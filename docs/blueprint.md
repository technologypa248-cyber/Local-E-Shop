# **App Name**: Local E-Shop

## Core Features:

- Product Browsing: Allow users to browse products, filter by category, and search.
- Product Details: Display detailed product information including images, description, price, and stock.
- Add to Cart: Enable users to add products to a shopping cart.
- Admin Authentication: Secure login for administrators using JWT authentication.
- Product Management: Allow admins to add, edit, and delete products, manage categories, and update stock levels.
- Category Management: Allow admins to create and manage product categories.
- Auto-Seed: Automatically seed the MongoDB database with initial product data on the first run. Checks if the database is empty; if so, it populates the database with static data and locks the seed functionality to prevent repeats.

## Style Guidelines:

- Primary color: Soft lavender (#E6E6FA) to create a calm and inviting shopping experience.
- Background color: Off-white (#F5F5F5), subtly desaturated, for a clean and neutral backdrop.
- Accent color: Pale violet red (#D87093), offering a touch of sophistication while maintaining visual harmony.
- Body font: 'PT Sans', a humanist sans-serif, to provide a modern look with warmth; use it for both headlines and body text.
- Use simple, consistent icons for navigation and product categories.
- Clean, grid-based layout to showcase products effectively.
- Subtle transitions for product details and cart updates.
